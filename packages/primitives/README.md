# @sail-ui/primitives

Interaction composables for [Sail UI](https://github.com/baiwumm/sail-ui): `useHover`, `usePress`, `useFocusRing` and `useOverlayState`. They emit the same `data-hovered` / `data-pressed` / `data-focus-visible` / `data-entering` / `data-exiting` attributes the HeroUI v3 CSS selects on, for the states Reka UI does not provide.

Used by `@sail-ui/vue`; you only need this package for custom components that must match the Sail UI interaction contract.

## Install

```sh
pnpm add @sail-ui/primitives
```
